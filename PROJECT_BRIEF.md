# Project Brief — Task Manager

## Project Name
GrowthLift Task Manager

## One-line description
A simple task manager web app where users can register, log in, and manage their personal to-do list — add tasks, mark them complete, and delete them.

## Target user
Anyone who wants a lightweight, no-frills personal task tracker — students or professionals juggling daily to-dos who don't want a bloated app.

## Core pages/features (max 5)
1. Login / Register page
2. Dashboard — view all tasks
3. Add new task
4. Mark task as complete (toggle)
5. Delete task

## Tech stack
- Frontend: React (Vite), React Router, Context API
- Backend: Express.js, JWT authentication, bcrypt
- Database: MongoDB (Mongoose)

## Timeline
- Day 2: Backend setup — models, auth routes, task routes, deploy-ready structure
- Day 3: Frontend setup — pages, routing, context, API integration
- Day 4: Connect frontend to backend, test full flow, styling polish
